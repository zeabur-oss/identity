发现安全漏洞时，通过这个仓库的 GitHub **Report a vulnerability** 私下报告。不要为安全问题创建公开 issue。

## 私下报告漏洞

在这个仓库的 GitHub 页面选择 **Report a vulnerability**，使用 GitHub 的私密漏洞报告功能提交问题。

## 支持的版本

只有最新发布的版本会收到安全补丁。安全补丁发布后，请升级到该版本。

## 升级前的准备

升级前，先阅读该版本的发布说明。保留独立的集群管理员凭据，并准备好经过恢复测试的备份：

- 按照[保留不经过 Zeabur Identity 的入口](../operations/emergency-access.mdx)，保留独立的管理入口。
- 按照[备份与恢复](../operations/backup-restore.mdx)，准备并测试备份。

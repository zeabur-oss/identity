你可以在这里查看 Zeabur Identity 实现的每项 MUST 和 SHOULD 要求，以及对应的代码和测试。Zeabur Identity 还没有获得 OpenID 认证。

规范用语遵循 RFC 2119 和 RFC 8174。各 crate 的文档包含设计理由和完整引用来源，你可以用以下命令打开：

```sh
cargo doc --workspace --open
```

表格保留来源的要求和状态文字。状态定义如下：

- **Met**：已有实现代码和测试。
- **Partial**：部分符合，限制写在该行。
- **Not implemented**：尚未实现。
- **N/A**：不适用，原因写在该行。

代码路径以 `crates/` 为基准。单元测试格式为 `crate: module::tests::name`，集成测试格式为 `crate/tests/file.rs: name`。

标记为 *(cluster)* 的测试使用 k3s `v1.36.5`，运行时使用 `--run-ignored only`。标记为 *(e2e)* 的测试位于 `zeabur-identity-e2e/tests/e2e.rs`，使用 Zeabur Identity 容器镜像运行。

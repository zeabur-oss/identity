title: 安全性與支援政策
description: 了解如何私下回報安全性弱點，以及哪些版本會收到安全修補。
---

如果發現安全性弱點，請使用這個儲存庫的 GitHub **Report a vulnerability** 功能私下回報。不要為安全性問題建立公開 issue。

## 私下回報弱點

在這個儲存庫的 GitHub 頁面選擇 **Report a vulnerability**，就能使用 GitHub 的私密弱點回報功能提交問題。

## 支援的版本

只有最新發布的版本會收到安全修補。安全修補發布後，請升級到該版本。

## 升級前的準備

升級前，請先讀該版本的發行說明。請保留獨立的叢集管理員認證資訊，並備妥已通過還原測試的備份：

- 依照[保留不經過 Zeabur Identity 的入口](../operations/emergency-access.mdx)，保留獨立的管理入口。
- 依照[備份與還原](../operations/backup-restore.mdx)，準備並測試備份。

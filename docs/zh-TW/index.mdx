Zeabur Identity 在你的叢集裡簽發登入權杖。`kubectl` 會開啟瀏覽器，讓你用通行密鑰驗證身分，拿到的權杖只在幾分鐘內有效。你不再需要把同一份管理員 kubeconfig 複製到每台筆電。

目前版本是 v0.1.1 alpha，版本之間可能有破壞性變更，升級或回復都可能失敗。請先在可隨時丟棄的叢集上試用，詳見[安全性與支援政策](reference/security.mdx)。

## 從一台 Ubuntu 伺服器開始

準備一台 Ubuntu 伺服器和你的電腦。跟著以下教學裝好 k3s 和 Zeabur Identity，再建立第一位管理員的通行密鑰，最後在電腦上用 `kubectl` 登入。

[在 Ubuntu 的 k3s 上安裝，用通行密鑰登入 kubectl](get-started/quickstart.mdx)

## 安裝到既有叢集

準備叢集管理員的 kubeconfig，以及一個能用 HTTPS 開啟的 Issuer 網址。用 `zeabur-identityctl` 安裝 CRD 與清單，再讓 kube-apiserver 信任 Zeabur Identity。

[把 Zeabur Identity 安裝到既有叢集](get-started/existing-cluster.mdx)

## 安裝之後

- [新增與管理使用者](users/manage-users.mdx)：邀請同事、調整群組、加入第二把通行密鑰。
- [用 GitHub 登入](users/github-sign-in.mdx)或[用 Google 登入](users/google-sign-in.mdx)：連結既有帳號，方便日常登入。
- [註冊用戶端](users/clients.mdx)：讓 Grafana、Argo CD 也能用 Zeabur Identity 登入。
- [備份與還原](operations/backup-restore.mdx)和[保留不經過 Zeabur Identity 的入口](operations/emergency-access.mdx)：出問題時，你還能進入叢集。

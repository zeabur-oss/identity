# Security policy

Report vulnerabilities privately through GitHub's "Report a vulnerability" (private
vulnerability reporting) on this repository. Do not open public issues for security problems.

## Supported versions

Only the latest release receives security fixes. Fixes are delivered in a new release; older
releases are not backported. Upgrade to the latest release when a fix is published.

Before an upgrade, read its release notes. Keep an independent cluster-admin credential and a
tested backup; see [operations](docs/operations/emergency-access.mdx).
